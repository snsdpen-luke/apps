# apps

授業などで使う公開アプリの置き場。GitHub Pages で公開している。
公開URL：https://snsdpen-luke.github.io/apps/<アプリ名>/

## このリポジトリは完全な公開領域

ここに置いた物は、リンクを誰にも教えていなくても、置いた瞬間に世界へ公開された物として扱う。
Git の履歴も公開される。

置かない物：
- 生徒の個人情報（仮名化を含む）
- APIキー・トークン・.env 等の秘密情報
- 内部メモ・設計判断
- 公開してはいけない教材情報
- 生徒に見せてはいけない解答（答えを隠す必要があるテストは、ここでは作らない）

秘密情報を一度でもコミットしたら、削除しても履歴から読める。そのキーは必ず無効化して作り直す。

## 構成

1アプリ1フォルダ。`<アプリ名>/index.html` を入口にする。
